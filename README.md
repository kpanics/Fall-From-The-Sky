# 🌌 Fall From The Sky (by KPANIC)

«Fall From The Sky» — это серия уникальных, эстетичных и функциональных ресурспаков для Minecraft **1.21.4**, вдохновленная атмосферными треками **RomancePlanet**. 

> ⚡ **Зачем переплачивать коммерческим студиям и донат-серверам за «приватные» фишки, если можно взять качественный пак абсолютно бесплатно?**

---

## ✨ Что уже внутри релиза:

* **🔨 Грозовой молот (Mace):** Полностью измененный внешний вид стандартной булавы. Текстура перерисована по пикселям в агрессивном, массивном и футуристичном сине-бело-черном стиле. Теперь сокрушительные удары в падении с высоты выглядят по-настоящему монументально.
* **🛡️ Индикатор Починки (Mending Indicator):** Настоящее спасение для игроков на PvP-серверах и активных участников аукционов. Вам больше не нужно наводить мышку на каждую отдельную шмотку в инвентаре! Незеритовая броня (шлем, нагрудник, поножи, ботинки) с наложенными чарами Починки автоматически перекрашивается в эксклюзивный **мрачно-красный вампирский стиль**. Вы сразу увидите топовый предмет в один клик.

---

## 🛠️ Системные требования и зависимости:

1. **Версия игры:** Minecraft 1.21.4 (ресурспак использует актуальный `pack_format: 46`).
2. **Моды для работы CIT:** Сама булава работает на чистом ванильном клиенте. Однако для автоматического перекрашивания зачарованной брони (система Custom Item Textures) на вашем клиенте **обязательно** должен быть установлен один из следующих модов:
   * **CIT Resewn** (или актуальный рабочий форк под 1.21.4 для Fabric)
   * **CIT Reborn**
   * **OptiFine**

---

## 📂 Техническая информация для разработчиков

Синтаксис файлов конфигурации внутри папки `optifine/cit/` полностью адаптирован под новую современную систему компонентов Minecraft 1.20.5+. Проверка наличия чар Починки реализована через прямое считывание регулярных выражений:
```properties
components.enchantments.levels.~mending=regex:.*
```

## 📜 Лицензия и правила использования
Ресурспак распространяется абсолютно **бесплатно** для всех игроков. 
* Разрешено использовать в личных целях, на стримах и видео (с указанием авторства).
* Запрещено продавать, включать в платные сборки или выдавать за свой собственный контент на донат-платформах коммерческих серверов.
